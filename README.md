# Bayes Lab 

**Bayes Lab** is a clean, friendly, interactive laboratory for learning
Bayesian probability and reasoning.

It is designed as an educational and research-oriented tool, focused on
clarity, intuition, and correct mathematical foundations.

---

## ✨ Features

- Medical test Bayes (PPV / NPV) with confusion matrix
- Visual intuition (prior → posterior comparison)
- Multi-hypothesis Bayesian normalization
- Step-by-step derivations
- Offline deterministic tutor (no AI, no tracking)
- Safe mathematical calculator (no `eval`)
- Privacy-first (no analytics, no tracking cookies)
- Responsive, premium UI

---

## 🎓 What you will learn

- Bayes’ theorem and its interpretation
- Base rate fallacy and diagnostic reasoning
- Evidence normalization for multiple hypotheses
- Difference between intuition and probability
- How priors influence posterior beliefs

---

## 🔐 Privacy (When using website because Bayes Lab is Open-source so you can use it offline)

Bayes Lab:
- does **not** use tracking cookies
- does **not** use analytics
- stores only local preferences (theme, settings) in the browser

No personal data is collected or transmitted.
